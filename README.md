## Executar localmente

O site usa HTML e CSS e não precisa de instalação ou compilação. Abra `index.html` no navegador ou execute:

```sh
python3 -m http.server 8000
```

Acesse http://localhost:8000.

## Publicação

Publique a pasta raiz em qualquer hospedagem de sites estáticos. O arquivo de entrada é `index.html` e as imagens estão em `assets/`.
